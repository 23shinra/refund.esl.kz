# Refund — сервис подбора льгот

Refund помогает быстро найти нужную тему по льготам и государственным услугам: вы выбираете раздел/подкатегорию, получаете список вопросов и читаете подробный ответ на странице вопроса. На каждой странице также есть контакты специалистов, которые помогут с оформлением.

## Что есть на сайте
- Главная: выбор аудитории (физические/юридические лица) и быстрый вход в разделы каталога.
- Каталог: список вопросов по выбранной подкатегории + поиск внутри раздела.
- Страница вопроса: ответ, теги и контакты помощников.
- Глобальный поиск в шапке: быстрые подсказки (есть режим поиска через “ИИ”).
- Заявка через WhatsApp: форма с проверкой номера телефона и открытием чата с предзаполненным текстом.
- Партнёрам и кабинет партнёра: страницы с описанием подписки и функциональность партнёрского дашборда.
- Документы: отдельные страницы Terms / Offer / Privacy.
