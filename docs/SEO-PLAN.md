# План улучшения SEO (Google + Яндекс)

Сайт: Qoldau (SPA на React/Vite). Ниже — приоритеты и задачи для органического поиска в **Google** и **Яндекс**.

---

## 1. Техническое SEO (высокий приоритет)

| Задача | Зачем | Действия |
|--------|--------|----------|
| **Индексация SPA** | Боты должны видеть контент страниц | SSR (например Vite SSR / prerender) или **пререндер** ключевых URL (`/`, `/about`, `/legal/*`, топ категорий) в HTML при сборке или через сервис. |
| **Чистые URL** | Уже ок (`/category/...`) | Не менять структуру без редиректов 301. |
| **HTTPS + редирект с www** | Доверие и единый домен | Проверить: только `https://qoldau.esl.kz`, 301 с дублей. |
| **robots.txt** | Управление обходом | Файл в `public/robots.txt`: `Allow: /`, `Sitemap: https://qoldau.esl.kz/sitemap.xml`. |
| **XML Sitemap** | Быстрый обход | Генерация sitemap (все статические + все категории/вопросы из каталога). Обновлять при смене данных. |
| **meta robots** | Закрыть служебное | `noindex` для `/admin`, при необходимости для `/partner`. |
| **Скорость (Core Web Vitals)** | Ранжирование Google | Сжатие, кеш статики, lazy images, минимизация JS на первом экране. |
| **Мобильная версия** | Mobile-first | Адаптив уже есть — проверить в PageSpeed / Search Console. |

---

## 2. Мета-теги и заголовки (on-page)

| Задача | Google | Яндекс |
|--------|--------|--------|
| **Уникальный `<title>`** | Да | Да — важны ключевые слова в начале |
| **Meta description** | Сниппет | Сниппет — до ~160–200 символов, уникальный на раздел |
| **H1 один на страницу** | Да | Да |
| **Иерархия H2–H3** | Да | Да |
| **hreflang** | Для мультиязычности | Яндекс тоже учитывает | Для RU/KZ: `<link rel="alternate" hreflang="ru" href="...">` и `hreflang="kk"` (или `kz` по стандарту) для парных URL |

**Рекомендация:** завести в данных или i18n для каждой категории/страницы: `seoTitle`, `seoDescription`, `ogTitle`, `ogDescription`.

---

## 3. Структурированные данные (Schema.org)

- **WebSite** + **SearchAction** (если поиск по сайту отдаёт URL — можно указать).
- **Organization** (название, url, logo, contactPoint).
- **WebPage** / **FAQPage** — если на странице вопрос–ответ по смыслу подходит.
- Разметка **JSON-LD** в `<head>` — удобнее для SPA при SSR/prerender.

Проверка: [Google Rich Results Test](https://search.google.com/test/rich-results), в Яндекс — Валидатор микроразметки.

## 4. Яндекс — специфика

| Задача | Где |
|--------|-----|
| **Яндекс.Вебмастер** | Добавить сайт, sitemap, проверка региональности (Казахстан). |
| **Турбо-страницы** | Опционально — RSS/турбо-ленты для новостей; для справочника не обязательно. |
| **Яндекс.Метрика** | Цели, вебвизор, карта кликов — косвенно помогает доработкам под поведение. |
| **Словоформы и синонимы** | Тексты на RU — естественные формулировки («льготы», «пособия», «выплаты»). |

## 6. Контент и семантика

1. **Кластеры запросов** под аудитории: физлица / юрлица, регион (Казахстан), темы (семья, образование, инвалиды и т.д.).
2. **Уникальные вводные тексты** на страницах категорий (не только список вопросов).
3. **Внутренняя перелинковка:** с главной на категории, между смежными темами, «похожие услуги».
4. **ALT у изображений** — если появятся иллюстрации.
5. **ЧПУ и осмысленные slug** — уже есть (`ind-family-payments` и т.д.).

---

## 7. Приоритетный порядок внедрения

1. **robots.txt + sitemap.xml** (быстро, большой эффект для обхода).  
2. **Уникальные title/description** для главной, «О нас», юридических страниц, топ-10 категорий.  
3. **Пререндер или SSR** для главной и публичных разделов — критично для SPA.  
4. **Organization + WebSite JSON-LD**.  
5. **Подключение Вебмастера + Search Console + Метрика/GA4**.  
6. Доработка текстов и перелинковка по мере аналитики запросов.

---

## 8. Метрики успеха (через 3–6 месяцев)

- Рост показов и кликов в GSC и Вебмастере.  
- Доля страниц в индексе (без «Discovered / not indexed» из‑за пустого HTML).  
- Средняя позиция по целевым запросам (льготы Казахстан, пособия и т.д.).  
- Органический трафик в Метрике/GA4.
