# План: мобильное меню и адаптация

## Цели
- Удобная навигация на экранах &lt; ~960px (текущая шапка перегружена: поиск + много ссылок в одну строку).
- Доступность: кнопка меню с `aria-expanded`, закрытие по Escape и клику по фону, блокировка прокрутки `body`.

## Решение
1. **Брейкпоинт** `960px`: ниже — мобильная шапка, выше — текущий десктопный вид.
2. **Мобильная шапка (2 ряда):**
   - ряд 1: логотип + кнопка «меню» (гамбургер);
   - ряд 2: полноширинный глобальный поиск (как сейчас).
3. **Выезжающая панель справа:** О нас, Партнёрам, ссылки документов (3), кабинет партнёра (если роль), вход/выход + роль, переключатель RU/KAZ.
4. **Тема:** в `theme.js` — `breakpoints.navDesktopMin: 960` для единообразия.

## Дополнительная адаптация
- **AppLayout:** чуть меньше горизонтальные отступы на очень узких экранах (`max-width: 100%`, `padding` clamp).
- **Страницы:** при необходимости — только точечные правки (таблицы, длинные строки); приоритет — Navbar.

## Проверка
- iPhone SE ширина, 390px, десктоп 1024px.
- Клавиатура: Tab по пунктам меню, Escape закрывает меню.

---

## Статус (реализация)
- Брейкпоинт `theme.breakpoints.navDesktopMin` (960px).
- Navbar: второй ряд — поиск; кнопка меню 44×44; drawer справа с теми же ссылками + документы + язык + вход/выход.
- Закрытие меню: переход по маршруту, Escape, фон, ×.
- `body { overflow: hidden }` пока drawer открыт.
- Строки i18n: `nav.menuOpen`, `nav.menuClose`, `nav.menuTitle` (RU/KZ).
- AppLayout: `padding` через `clamp` на узких экранах.
